# 선생님용 AI 위키 시작 폴더

AI 에이전트(Antigravity, Claude Code, Codex 등)와 함께 쓰는 **개인 업무 위키**의 빈 틀입니다.
자료를 한 폴더에 모아 두면 AI가 규칙에 따라 읽고, 정리하고, 목차와 기록을 갱신합니다.
매번 처음부터 설명하지 않아도 AI가 이전에 정리한 문서를 이어서 고칩니다.

Andrej Karpathy가 제안한 "LLM Wiki" 방식을 교사 업무에 맞게 줄인 것입니다.
검색이 아니라 **한 번 정리해 두고 계속 고쳐 쓰는 것**이 핵심입니다.

## 시작하기

1. 이 페이지 위쪽의 **Use this template → Create a new repository**를 누릅니다.
   저장소 공개 범위는 반드시 **Private**으로 고릅니다.
2. [GitHub Desktop](https://desktop.github.com)에서 방금 만든 저장소를 **Clone**합니다.
   위치는 `문서` 폴더처럼 Google 드라이브·OneDrive 동기화 폴더가 **아닌** 곳을 고릅니다.
3. AI 에이전트 앱에서 그 폴더를 엽니다 (Antigravity: File → Open Folder).
4. 에이전트 대화창에 [첫 설정 프롬프트](docs/첫-설정-프롬프트.md)를 붙여 넣습니다.

GitHub를 쓰지 않으려면 **Code → Download ZIP**으로 받아 `문서` 폴더에 풀어도 됩니다.

## 폴더 구조

| 폴더·파일 | 들어갈 것 |
|---|---|
| `원본/` | 받은 공문, 교육과정 문서, 연수 자료. AI가 고치지 않습니다 |
| `수업/` | 단원별 수업 설계, 활동지, 평가 문항 |
| `업무/` | 가정통신문, 회의 정리, 행사·업무 계획 |
| `개념/` | 여러 곳에 두루 쓰는 개념 정리 (평가 방법, 수업 모형 등) |
| `_inbox/` | AI가 "남길 만하다"고 본 후보 초안. 사람이 보고 옮기거나 지웁니다 |
| `templates/` | 새 문서의 틀 |
| `GUIDE.md` | AI가 따르는 규칙 본문 |
| `AGENTS.md` · `GEMINI.md` · `CLAUDE.md` | 도구별 진입점. 모두 `GUIDE.md`를 읽으라고만 적혀 있습니다 |
| `index.md` | 모든 문서의 한 줄 목차 |
| `log.md` | 날짜별 작업 기록 |
| `개선-요청.md` | AI 작업 방식에 대한 고칠 점 목록 |

## 꼭 지킬 것

- **학생 개인정보(이름, 성적, 상담 기록, 연락처)는 이 폴더에 넣지 않습니다.** 비공개 저장소라도 넣지 않습니다.
- AI가 틀리면 대화로만 고치지 말고 `GUIDE.md`에 규칙을 한 줄 더합니다. 대화는 잊히지만 규칙 파일은 매번 읽힙니다.
