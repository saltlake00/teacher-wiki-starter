# 선생님용 AI 위키 시작 폴더

AI 에이전트(Antigravity, Claude Code, Codex 등)와 함께 쓰는 **개인 업무 위키**의 빈 틀입니다.
자료를 한 폴더에 모아 두면 AI가 규칙에 따라 읽고, 정리하고, 목차와 기록을 갱신합니다.
매번 처음부터 설명하지 않아도 AI가 이전에 정리한 문서를 이어서 고칩니다.

Andrej Karpathy가 제안한 "LLM Wiki" 방식을 교사 업무에 맞게 줄인 것입니다.
검색이 아니라 **한 번 정리해 두고 계속 고쳐 쓰는 것**이 핵심입니다.

## 시작하기 — AI에게 한 줄로 맡기기

1. [Claude 데스크톱 앱](https://claude.ai/download)을 설치하고 로그인합니다.
   폴더를 열고 파일을 고치는 **Code** 탭은 Pro 이상 요금제에서 쓸 수 있습니다.
2. `문서` 안에 빈 폴더 `AI작업`을 만들고, Claude 앱의 **Code** 탭에서 그 폴더를 엽니다.
3. 대화창에 아래 한 줄을 붙여 넣습니다.

```text
https://github.com/saltlake00/teacher-wiki-starter 의 README를 읽고 "AI 에이전트용 설치 순서"대로 내 위키를 세팅해 줘.
```

AI가 위키 받기 → 첫 설정 → GitHub 백업 순서로 하나씩 묻고 진행합니다.
명령을 실행하거나 파일을 고치기 전에 승인 창이 뜨면, 무엇을 하려는지 읽고 누릅니다.

단계를 직접 하나씩 하고 싶으면 [프롬프트 모음](docs/첫-설정-프롬프트.md)의 ①~③을 차례로 붙여 넣어도 됩니다.
Antigravity, Codex 같은 다른 AI 에이전트에서도 같은 방법이 통합니다.

## AI 에이전트용 설치 순서

> 이 절은 사용자의 요청을 받아 이 README를 읽은 AI 에이전트를 위한 순서입니다.
> 사용자는 AI 도구를 처음 쓰는 선생님입니다. 쉬운 말로 설명하고, 단계마다 무엇을 하는지 한 줄로 알린 뒤 진행합니다.
> 명령 실행과 파일 생성 전에는 보여 주고 확인을 받습니다. 이 순서 밖의 일은 하지 않습니다.

**1단계: 위키 받기**

- 사용자의 `문서` 폴더 안에 `내위키` 폴더를 만들고, 이 저장소를 ZIP으로 받아 풉니다.
  주소: `https://github.com/saltlake00/teacher-wiki-starter/archive/refs/heads/main.zip`
- ZIP 안의 `teacher-wiki-starter-main` 폴더 **내용물**이 `내위키` 바로 아래에 오게 합니다. `git clone`은 쓰지 않습니다(이 저장소가 원격으로 연결되지 않게).
- `내위키`가 이미 있고 비어 있지 않으면 멈추고 사용자에게 묻습니다.
- 받은 ZIP은 지웁니다. 다른 파일은 건드리지 않습니다.
- `내위키` 폴더는 Google 드라이브·OneDrive 동기화 폴더 안에 두지 않습니다.
- 끝나면 파일 목록을 보여 주고, 앱에서 `내위키` 폴더를 여는 방법을 안내합니다. 이후 단계는 그 폴더에서 진행합니다.

**2단계: 첫 설정**

- `GUIDE.md`를 읽고 규칙을 다섯 줄 이내로 요약해 사용자에게 보여 줍니다.
- 다음 네 가지를 하나씩 묻습니다: 학교급, 가르치는 과목, 담당 학년과 업무, AI에게 자주 맡기고 싶은 일 세 가지.
- 답으로 `index.md`의 "내 정보"를 채웁니다.
- `수업/`·`업무/` 아래 하위 폴더 이름을 제안하고, 승인을 받으면 만듭니다. 각 폴더에 한 줄짜리 `README.md`를 둡니다.
- `log.md`에 오늘 날짜로 "위키 첫 설정"을 적습니다. 바꾼 파일 목록을 보여 줍니다.

**3단계: GitHub 백업 (사용자가 원할 때만)**

- 백업을 원하는지 먼저 묻습니다. 원하지 않으면 4단계로 갑니다.
- Git이 설치되어 있는지 확인합니다. 없으면 설치 방법을 알려 주고 이 단계를 멈춥니다.
- GitHub 계정이 없으면 [github.com](https://github.com)에서 **개인 메일**로 가입하도록 안내합니다(학교 메일은 전보·퇴직 때 사라질 수 있음).
- 사용자에게 이름과 GitHub 가입 메일을 물어 이 폴더에만 `git config user.name`·`user.email`을 설정합니다.
- `git init -b main` 후 첫 커밋을 합니다. `git add -A`나 `git add .`는 쓰지 않고 파일을 하나씩 지정합니다.
  커밋 전에 올릴 파일 목록을 보여 주고, 학생 개인정보로 보이는 파일이 없는지 확인합니다. 커밋 메시지는 한국어로 씁니다.
- github.com에서 **비공개(Private) 빈 저장소**를 만드는 방법을 안내합니다. 이름 예: `my-wiki`. README·.gitignore·라이선스는 추가하지 않게 합니다.
  사용자가 저장소 주소를 알려 줄 때까지 기다립니다.
- 그 주소를 `origin`으로 연결하고 `git push -u origin main`을 합니다. 로그인 창이 뜨면 사용자가 브라우저에서 로그인하도록 안내합니다.
- 끝나면 저장소 주소를 알려 주고, 저장소가 Private인지 사용자와 함께 확인합니다.

**4단계: 마무리**

- 앞으로 쓸 말 세 가지를 예로 알려 줍니다. [프롬프트 모음](docs/첫-설정-프롬프트.md)의 ④ 표에서 사용자의 답(자주 맡길 일)에 맞는 것을 고릅니다.
- 백업을 설정했다면 "오늘 바뀐 파일 목록을 보여 주고, 내가 확인하면 커밋하고 푸시해 줘"라고 말하면 된다고 알립니다.
- 학생 이름·성적·상담 내용은 넣지 않는다는 점을 다시 알립니다.

## 직접 하고 싶을 때

GitHub 화면에서 **Use this template → Create a new repository**로 비공개(Private) 사본을 만들고,
[GitHub Desktop](https://desktop.github.com)으로 Clone한 뒤 AI 앱에서 그 폴더를 열어도 됩니다.
그다음 [프롬프트 모음](docs/첫-설정-프롬프트.md)의 ②를 붙여 넣습니다. 이때는 3단계의 저장소 만들기가 필요 없습니다.

## 폴더 구조

| 폴더·파일 | 들어갈 것 |
|---|---|
| `원본/` | 받은 공문, 교육과정 문서, 연수 자료. AI가 고치지 않습니다 |
| `수업/` | 단원별 수업 설계, 활동지, 평가 문항 |
| `업무/` | 가정통신문, 회의 정리, 행사·업무 계획 |
| `개념/` | 여러 곳에 두루 쓰는 개념 정리 (평가 방법, 수업 모형 등) |
| `_inbox/` | AI가 "남길 만하다"고 본 후보 초안. 사람이 보고 옮기거나 지웁니다 |
| `templates/` | 새 문서의 틀 |
| `GUIDE.md` | AI가 따르는 규칙 본문 |
| `AGENTS.md` · `GEMINI.md` · `CLAUDE.md` | 도구별 진입점. 모두 `GUIDE.md`를 읽으라고만 적혀 있습니다 |
| `index.md` | 모든 문서의 한 줄 목차 |
| `log.md` | 날짜별 작업 기록 |
| `개선-요청.md` | AI 작업 방식에 대한 고칠 점 목록 |

## 꼭 지킬 것

- **학생 개인정보(이름, 성적, 상담 기록, 연락처)는 이 폴더에 넣지 않습니다.** 비공개 저장소라도 넣지 않습니다.
- AI가 틀리면 대화로만 고치지 말고 `GUIDE.md`에 규칙을 한 줄 더합니다. 대화는 잊히지만 규칙 파일은 매번 읽힙니다.
