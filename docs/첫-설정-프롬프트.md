# AI 에이전트에게 붙여 넣는 프롬프트

Claude 데스크톱 앱 Code 탭의 대화창에 상자 안의 글을 그대로 붙여 넣습니다.
AI가 명령을 실행하거나 파일을 고치기 전에 승인 창이 뜨면, 무엇을 하려는지 읽고 누릅니다.

## ① 위키 받기 (빈 폴더를 연 뒤)

`문서\AI작업` 같은 빈 폴더를 연 상태에서 붙여 넣습니다.

```text
https://github.com/saltlake00/teacher-wiki-starter 의 내용을 내 컴퓨터 "문서" 폴더 안 "내위키" 폴더로 복사해 줘.
- git clone 말고 ZIP으로 받아서 풀어 줘: https://github.com/saltlake00/teacher-wiki-starter/archive/refs/heads/main.zip
- ZIP 안의 teacher-wiki-starter-main 폴더 내용물이 "내위키" 바로 아래에 오게 해 줘.
- 받은 ZIP은 풀고 나서 지워도 돼. 다른 파일은 건드리지 마.
- 실행할 명령을 먼저 보여 주고, 내가 좋다고 하면 실행해.
- 다 되면 "내위키" 폴더의 파일 목록을 보여 주고, 앱에서 그 폴더를 여는 방법을 알려 줘.
```

## ② 첫 설정 (`내위키` 폴더를 연 뒤 한 번)

```text
이 폴더는 내 개인 업무 위키야. 먼저 GUIDE.md를 끝까지 읽고 규칙을 요약해 줘.

그다음 나에게 아래 네 가지를 하나씩 물어봐.
1. 학교급 (초·중·고)
2. 가르치는 과목
3. 담당 학년과 맡은 업무
4. AI에게 가장 자주 맡기고 싶은 일 세 가지

답을 받으면:
- index.md의 "내 정보"를 채워 줘.
- 수업/ 과 업무/ 아래에 만들 하위 폴더 이름을 제안해 줘. 내가 좋다고 하면 만들어.
- log.md에 오늘 날짜로 "위키 첫 설정"을 적어 줘.
- 마지막에 바꾼 파일 목록을 보여 줘.

규칙: 원본/ 은 건드리지 말고, 파일을 지우거나 옮길 때는 먼저 물어봐.
```

## ③ GitHub 백업 설정 (선택, 한 번)

`내위키` 폴더를 연 상태에서 붙여 넣습니다. GitHub 가입은 미리 해 둡니다([github.com](https://github.com), 학교 메일 말고 **개인 메일**).

```text
이 위키 폴더를 내 GitHub 비공개 저장소에 백업하도록 설정해 줘. 나는 Git을 처음 써. 한 단계씩 진행하고, 단계마다 무엇을 하는지 한 줄로 설명해 줘.

1. Git이 설치되어 있는지 확인해 줘. 없으면 설치 방법을 알려 주고 멈춰.
2. git에 쓸 내 이름과 이메일을 나에게 물어보고 설정해 줘. 이메일은 GitHub 가입 메일로 할게.
3. 이 폴더에 이미 .git이 있으면 알려 줘. 없으면 저장소를 만들고 기본 브랜치를 main으로 해 줘.
4. 첫 커밋을 해 줘. git add -A 나 git add . 는 쓰지 말고 파일 이름을 하나씩 지정해.
   커밋하기 전에 올릴 파일 목록을 보여 주고, 학생 개인정보로 보이는 파일이 없는지 확인해 줘.
5. github.com에서 비공개 빈 저장소를 만드는 방법을 알려 줘.
   이름은 my-wiki, 공개 범위는 Private, README·.gitignore·라이선스는 추가하지 않게.
   내가 다 만들고 저장소 주소를 알려 주면 다음으로 넘어가.
6. 그 주소를 origin으로 연결하고 push해 줘. 로그인 창이 뜨면 내가 브라우저에서 로그인할게.
7. 끝나면 GitHub 저장소 주소와, 앞으로 백업할 때 나에게 하라고 할 말을 한 줄로 알려 줘.
```
