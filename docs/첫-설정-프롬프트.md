# AI 에이전트에게 붙여 넣는 프롬프트

Antigravity 같은 AI 에이전트 앱의 대화창에 아래 상자 안의 글을 그대로 붙여 넣습니다.

## A. 폴더 받기까지 AI에게 맡길 때

빈 폴더(예: `문서\AI작업`)를 앱에서 연 뒤 붙여 넣습니다. GitHub를 쓰지 않는 방법입니다.

```text
https://github.com/saltlake00/teacher-wiki-starter 의 내용을 내 컴퓨터 "문서" 폴더 안 "내위키" 폴더로 복사해 줘.
- git clone 말고 ZIP으로 받아서 풀어 줘: https://github.com/saltlake00/teacher-wiki-starter/archive/refs/heads/main.zip
- 받은 ZIP은 풀고 나서 지워도 돼. 다른 파일은 건드리지 마.
- 실행할 명령을 먼저 보여 주고, 내가 좋다고 하면 실행해.
- 다 되면 "내위키" 폴더의 파일 목록을 보여 주고, 앱에서 그 폴더를 여는 방법을 알려 줘.
```

복사가 끝나면 앱에서 `내위키` 폴더를 열고 B로 넘어갑니다.

## B. 첫 설정 (폴더를 연 뒤 한 번)

```text
이 폴더는 내 개인 업무 위키야. 먼저 GUIDE.md를 끝까지 읽고 규칙을 요약해 줘.

그다음 나에게 아래 네 가지를 하나씩 물어봐.
1. 학교급 (초·중·고)
2. 가르치는 과목
3. 담당 학년과 맡은 업무
4. AI에게 가장 자주 맡기고 싶은 일 세 가지

답을 받으면:
- index.md의 "내 정보"를 채워 줘.
- 수업/ 과 업무/ 아래에 만들 하위 폴더 이름을 제안해 줘. 내가 좋다고 하면 만들어.
- log.md에 오늘 날짜로 "위키 첫 설정"을 적어 줘.
- 마지막에 바꾼 파일 목록을 보여 줘.

규칙: 원본/ 은 건드리지 말고, 파일을 지우거나 옮길 때는 먼저 물어봐.
```

## C. 평소에 쓰는 말

| 하고 싶은 일 | 이렇게 말합니다 |
|---|---|
| 받은 자료 정리 | `원본/에 넣은 ○○ 연수 자료를 읽고 수업에 쓸 내용만 정리해 줘` |
| 수업 준비 | `3학년 과학 물질의 상태 단원 활동지 초안을 만들어 줘. 기존 문서가 있으면 이어서 고쳐` |
| 통신문 초안 | `다음 주 현장체험학습 가정통신문 초안을 써 줘. 날짜와 장소는 내가 줄게` |
| 다시 찾기 | `전에 만든 평가 문항 중에 서술형만 모아서 보여 줘` |
| 후보 검토 | `_inbox에 있는 후보를 보여 주고, 정식 문서로 옮길 만한 것을 골라 줘` |
| AI 실수 고치기 | `방금처럼 성취기준 코드를 지어내지 않도록 GUIDE.md에 규칙을 한 줄 추가해 줘` |
| 백업 (GitHub를 쓸 때) | `오늘 바뀐 파일 목록을 보여 주고, 내가 확인하면 커밋하고 푸시해 줘` |

학생 이름, 성적, 상담 내용은 넣지 않습니다.
